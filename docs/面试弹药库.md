## 一、17 条"经得住拷问"规格表

**接不住拷问的功能，不做。** 这是项目范围的唯一控制依据。

### 通用 10 条

| # | 面试官会问 | 答案要点 | 模块 | 状态 |
|---|-----------|---------|------|------|
| 1 | 你怎么知道检索有效？ | 评估集 + 改一次参数跑一遍，Hit@3 从 X 提到 Y | M5 | ⬜ |
| 2 | 为什么混合检索不是纯向量？ | 法条编号类查询向量会飘，BM25 字面命中；有实测对比数据 | M3 | ⬜ |
| 3 | rerank 为什么不放召回阶段？ | cross-encoder 是 O(n)，全库跑不动，只能精排 top-20 | M3 | ⬜ |
| 4 | 一个知识库 10 万文档会怎样？ | 先撑不住的是 Chroma 全量加载 + BM25 全内存；`VectorStore` 是抽象接口，换 Qdrant 只改实现类 | M3 | ⬜ |
| 5 | 文档更新了怎么办？ | file_hash 幂等，内容变了 delete+re-add；chunk 表是真相源可重建 | M2 | ⬜ |
| 6 | 用户 A 能看到 B 的文档吗？ | kb_id 在**检索 / 拼 prompt / 引用展示 / 原文下载**四处强制过滤 | M3+M4 | ⬜ |
| 7 | 怎么防幻觉？ | 三层：检索侧阈值过滤、生成侧强制引用、追溯侧引用校验 | M4 | ⬜ |
| 8 | LLM 挂了怎么办？ | Provider 抽象 + 降级 + 超时重试 | M0 | ⬜ |
| 9 | 成本怎么算？ | 每次问答落 trace，记 tokens × 单价 | M4 | ⬜ |
| 10 | Agent 会死循环吗？ | max_iterations + 反思节点 + **工具返回显式 not-found 而不是空串** | M6 | ⬜ |

| # | 面试官会问 | 答案要点 | 模块 | 状态 |
|---|-----------|---------|------|------|

## 四、已知局限（诚实清单）

> **面试时主动说出来，比被问出来强。**
> 主动说局限 = "我想清楚了"；被问出来 = "你没考虑到"。

| 局限 | 影响 | 为什么不解决 / 怎么缓解 |
|------|------|----------------------|
| 语料只覆盖 11 部劳动法相关法规 | 问题超出范围会拒答 | 第一版刻意收敛范围，追求"一个领域讲透" |
| 不做地方差异（加班费基数、最低工资各省不同） | 涉及地方标准的问题答不准 | metadata 预留 `region` 字段，第一版默认"全国" |
| 本地 7B 模型能力有限 | 复杂推理会翻车 | Provider 抽象可切云端；评估时如实记录 |
| ChromaDB 十万级文档会变慢 | 性能天花板 | VectorStore 抽象，换实现类 |
| 时效性字段依赖语料质量 | 部分失效可能漏标 | M2 有验证点；已知的必测用例（解释一第32条） |
| 重排依赖云端 API | 断网不可用 | 降级路径 + 演示前演练离线场景 |
| Citation F1 的"正确引用"由人工标注 | 评估集规模受限 | 抽样标注 + 复用问答日志 |

## 五、待补的面试问题

> 边做边记，遇到答不上来的就写进来。

- [ ] 为什么 chunk 不用滑窗？（→ ADR-009）
- [ ] 为什么关系库还要存一份 chunk 原文？（→ ADR-014 待写）
- [ ] 为什么检索配置存在 `knowledge_bases` 而不是配置文件？
      → 评估实验要"一次只改一个变量"。配置跟着知识库走，才能 A 库用 BM25、B 库用混合检索，用同一套评估集对比
- [ ] `kb_id` 为什么同时进 metadata 和关系库？
      → metadata 用于检索时过滤（性能和隔离），关系库用于溯源和展示。职责不同
- [ ] 分层依赖怎么保证不退化？
      → `import-linter` 强制，违规 CI 报错（抄 Dify）
